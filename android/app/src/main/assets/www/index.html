INSTALL IN THREE STEPS

From this page to your home screen

  1. 1 Download the APK with the button above. Use your phone, not a school computer.
  2. 2 Allow the install. Android may ask you to permit installs from your browser. Tap Settings, allow it, then return.
  3. 3 Open BrightPath and sign in. Turn on fingerprint unlock in your profile after the first sign-in.

Stuck? Ask a parent or guardian to help with the Android permission screen. Updates install over the app and keep your work.

A REAL ANDROID APP

Not a website shortcut

  • Signed APK with its own launcher icon and app window
  • Camera and microphone access for live classes
  • Fingerprint or face unlock backed by Android Keystore
  • Android reminders and a notification permission prompt
  • Lessons bundled with the app for offline reading

The browser version is a preview. For lessons and class tools on a phone, install the Android app.
